# Merge Shot — Playable Ad

A self-contained HTML5 playable demo of **Merge Shot** (Ball 2048 merge shooter),
used as a web playable ad. Single file, no external assets (game icons + sounds
are embedded). The download CTA uses the MRAID / ExitApi exit when running inside
an ad container, and falls back to opening the Play Store listing as a normal page.

- **Live page:** https://binaref.github.io/mergeshot-play/
- **Full game:** https://play.google.com/store/apps/details?id=com.binaref.mergeshot

Ends when the player reaches 1,000,000 points **or** after 10 minutes of play.
